# 💫 About Me:
Hi there! I'm Prathamesh Malandkar, a passionate and detail-oriented Front-End Developer with 1.5 years of professional experience at TCS. I specialize in building responsive and dynamic web interfaces using Angular, JavaScript, HTML5, CSS3, and Bootstrap, with backend knowledge in Spring Boot, Java, MySQL, PostgreSQL, and MongoDB.<br>I thrive in full-stack environments and love turning complex problems into clean, user-friendly solutions. From integrating REST APIs to optimizing UI performance, I’ve delivered impactful modules with high code quality and test coverage. Currently, I’m focused on enhancing my front-end expertise while staying open to full-stack challenges!<br>I believe in continuous learning, writing clean code, and growing through collaboration. You’ll often find me refining projects on GitHub or exploring new technologies that shape the future of web development.
